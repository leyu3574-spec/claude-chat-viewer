# Claude 对话浏览器 · 本地离线

一个单文件、完全离线的 Claude 对话记录查看器。把从 Claude 官方导出的数据包拖进来，就能在本地优雅地浏览、搜索全部历史对话。

## 特点

- **单文件**：只有一个 HTML 文件，无需安装，浏览器打开即用
- **完全离线**：所有解析和渲染都在本地完成，数据不会上传到任何服务器
- **浏览 + 搜索**：按时间线浏览全部对话，支持全文搜索

## 使用教程

### 第一步：从 Claude 导出你的数据

1. 在电脑浏览器打开 [claude.ai](https://claude.ai) 并登录
2. 点击左下角你的头像（或名字首字母）→「设置」
3. 进入「隐私」(Privacy) 分区，点击「导出数据」(Export data) 按钮
4. 等待导出生成，Claude 会把下载链接发到你账号绑定的邮箱
5. ⚠️ **下载链接 24 小时后过期**，收到邮件后尽快下载；过期了重新申请一次即可
6. ⚠️ **注意**：邮件附件可能只是一个索引 `.json` 文件，里面是几个下载链接——真正的对话数据要通过链接另外下载。打开这个索引文件，找到文件名或链接中包含 `conversations` 的那一个（通常叫 `conversations-000.zip`），复制链接到浏览器打开下载；其余链接是账户元数据等，可按需下载
7. ⚠️ 索引文件里的下载链接相当于一次性口令，**不要转发给他人**

> 说明：个人账号（Free / Pro / Max）均可自行导出；手机 App 上无法发起导出，请用网页版或桌面版；公司 Team / Enterprise 账号需由组织管理员（Primary Owner）操作。官方说明见 [How can I export my Claude data?](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data)

### 第二步：用查看器打开

1. 双击用浏览器打开 `claude-chat-viewer-2_0_rgon.html`
2. 把下载的 zip 包（或解压得到的 `conversations.json`）直接**拖进页面**，也可以点击选择文件
3. 等待解析完成，即可浏览、搜索全部对话

### 常见问题

- **提示"导出数据里没有这个文件的内容"**：导出包本身不含上传附件、程序库文件等原始内容，查看器只能按导出包里有的数据重建，能还原多少取决于导出包的内容
- **数据安全吗**：本工具是纯前端单文件，导入的文件只存在于你的浏览器本地，不会上传到任何服务器
