# Claude 对话浏览器 · 本地运行

> 🚀 **在线试用**：https://leyu3574-spec.github.io/claude-chat-viewer/（打开即用，无需下载）

一个单文件、在本地运行的 Claude 对话记录查看器。把从 Claude 官方导出的数据包拖进来，就能在本地浏览、搜索全部历史对话，还能接着上次的活继续干。

当前版本：**v3.6**

## 功能

### 浏览与搜索

- **时间线浏览**：按时间顺序浏览全部对话
- **全文搜索**：中文分词搜索，支持按标题搜、按项目筛选、排序
- **虚拟滚动**：只渲染屏幕内的消息，上万条消息也不卡
- **分支切换**：对话里的编辑或重新生成会留下分支，可以只看最新分支，也能切回全部分支
- **思考过程**：Claude 的思考块可以展开查看，也能一键全部展开

### 渲染

- **Markdown**：标题、列表、引用、表格等正常排版
- **代码块**：可以一键复制，也能收起
- **数学公式**：内置 KaTeX，行内公式和整段公式都能渲染
- **Artifact**：按版本 id 和发布路径还原，重新导入会按内容重新排版
- **工具调用**：工具调用过程和返回结果都能看到
- **图片与附件**：对话里的图片、插图正常显示

### 项目与自动整理

- **项目列表**：和 Claude 里一样的项目列表，对话可以归入项目，也能按项目筛选
- **文件还原**：对话里改过的文件，会按工具调用重放还原出来

### 接班包

做到一半的活，不用从头给新对话讲背景，一键生成接班包就能接着干：

- **一键生成**：含全部项目文件的完整包
- **断点**：记录“停在哪里”，下次打开接着来
- **任务**：新建任务，标状态（待开始 / 进行中 / 受阻 / 已完成）、设优先级、关联任务
- **笔记**：决策、阻碍、失败尝试都能记下来
- **文件清单**：手动填或 AI 回填，分可信度档——精确还原、近似还原、只有声明、缺失
- **日志节制**：自动整理出的报错和测试日志只带最近几条，不挤占接班包的篇幅

### 隐私与安全

- **显示优先（默认，3.5 起）**：对话里的网络图片、图示和网页用到的在线库、字体都正常加载，显示效果和在 Claude 里看到的一致；加载时不带来源页面（no-referrer），不发送对话内容
- **严格离线（可选）**：在「数据 → 隐私与安全」里切换（`ccv-net-mode = offline`），用内容安全策略拦截一切网络请求
- **导入、解析和生成接班包都在本地完成**，不联网；数据只存在于你的浏览器本地，不会上传到任何服务器

### 其他

- **备份与恢复**：可以备份，换电脑后从备份恢复
- **导出与下载**：支持导出和下载
- **统计**：每个对话显示消息数和最后活跃时间
- **清单导入**：邮件里下载到的如果只是一个 JSON 清单（manifest），也直接拖进来，会列出每个数据包（对话、项目、记忆……）的下载按钮和还缺哪些，下载好后一起拖进来就行

## 使用教程

### 第一步：从 Claude 导出你的数据

1. 在电脑浏览器打开 [claude.ai](https://claude.ai) 并登录
2. 点击左下角你的头像（或名字首字母）→「设置」
3. 进入「隐私」(Privacy) 分区，点击「导出数据」(Export data) 按钮
4. 等待导出生成，Claude 会把下载链接发到你账号绑定的邮箱
5. ⚠️ **下载链接 24 小时后过期**，收到邮件后尽快下载；过期了重新申请一次即可
6. ⚠️ **注意**：邮件附件可能只是一个索引 `.json` 文件，里面是几个下载链接——真正的对话数据要通过链接另外下载。打开这个索引文件，找到文件名或链接中包含 `conversations` 的那一个（通常叫 `conversations-000.zip`），复制链接到浏览器打开下载；其余链接是账户元数据等，可按需下载。也可以直接把这个索引文件拖进查看器，它会列出每个数据包的下载按钮和还缺哪些
7. ⚠️ 索引文件里的下载链接相当于一次性口令，**不要转发给他人**

> 说明：个人账号（Free / Pro / Max）均可自行导出；手机 App 上无法发起导出，请用网页版或桌面版；公司 Team / Enterprise 账号需由组织管理员（Primary Owner）操作。官方说明见 [How can I export my Claude data?](https://support.claude.com/en/articles/9450526-how-can-i-export-my-claude-data)

### 第二步：用查看器打开

1. 双击用浏览器打开 `claude-chat-viewer-3.6_1_r0k2.html`（当前版本 v3.6）
2. 把下载的 zip 包（或解压得到的 `conversations.json`）直接**拖进页面**，也可以点击选择文件
3. 等待解析完成，即可浏览、搜索全部对话；解析结果会保存在本地数据库，下次打开直接接着用

### 常见问题

- **提示"导出数据里没有这个文件的内容"**：导出包本身不含上传附件、程序库文件等原始内容，查看器只能按导出包里有的数据重建，能还原多少取决于导出包的内容
- **导出里只有文字**：上传的 PDF、图片，Claude 生成的图片、压缩包都只有名字。电脑里有原件的话，一起拖进来就能离线显示
- **数据安全吗**：本工具是纯前端单文件，导入的文件只存在于你的浏览器本地，不会上传到任何服务器；需要完全断网时可以在「数据 → 隐私与安全」里切换到严格离线
