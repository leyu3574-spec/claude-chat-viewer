Claude 对话浏览器

单文件 · 完全离线 · 数据不出本机

把从 Claude 官方导出的数据包拖进来，在本地优雅地浏览、搜索你的全部历史对话。

🚀 在线试用 ⬇️ 下载单文件 ⭐ GitHub 仓库

✨ 特点

  • 只有一个 HTML 文件，无需安装，浏览器打开即用
  • 所有解析和渲染都在本地完成，不上传、不联网
  • 按时间线浏览全部对话，支持全文搜索
  • 虚拟滚动，上万条消息也不卡

📖 三步上手

  1. 在 claude.ai 设置 → 隐私中申请「导出数据」，下载包含 conversations 的 zip 包
  2. 点击上方「在线试用」，或下载单文件后双击打开
  3. 把 zip 包直接拖进页面，即可浏览、搜索
